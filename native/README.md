# PICO 原生桌宠使用与开发说明

仅支持 Windows 11 x64，原生 C++20 / Win32 / Direct3D 11。构建步骤、项目结构和能力边界见仓库根目录 README。

## 安装与启动

运行 PICO-Setup.exe，安装到 %LOCALAPPDATA%\Programs\PicoPet，注册开始菜单及当前用户 PATH 的 pet 命令。重新打开终端后输入 pet 唤起同一实例。便携版完整解压 ZIP 后运行 PicoPet.exe，保留同目录 PicoPet.Input.dll。再次安装可更新；卸载保留 %LOCALAPPDATA%\PicoPet 下的设置、图片和索引。默认不开机自启动，不添加服务或驱动。

偏好设置 → **启动与显示器** 可开启当前用户登录后的自启动，并选择记住上次位置或屏幕 1、屏幕 2 等指定显示器。选择自动保存，下次启动生效；指定显示器断开时回到主屏，保留原选择。自启动使用当前用户 Run 注册表项 `PicoPet.Win11`，关闭会移除；卸载清理指向当前安装目录的启动项。若任务管理器禁用了该启动项，需在那里重新启用。便携版移动目录后需重新关闭、开启自启动以更新路径。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动机身 | 移动；启用悬浮后根据轨迹产生惯性和回摆 |
| 滚轮 | 放大 / 缩小；进入终端保留当前大小 |
| 中键拖动、Alt + 左键拖动 | 调整三维朝向和俯仰 |
| 鼠标移入屏幕 | 显示系统模块和快捷方式 |
| 屏内加号 | 添加程序、文件、文件夹或 .lnk，最多 32 项 |
| 终端图标、普通模式下的机身助手按钮 | 开关屏内终端 |
| 电视应用运行时的红色按钮 | 关闭电视内应用，完成后返回图标桌面 |
| 机身、托盘、图标桌面右键；应用内 Shift + 右键 | 完整菜单及偏好设置；应用内普通右键交给应用 |
| 拖向工作区顶部 | 天线受压折叠，离开后回弹 |

偏好设置按“外观与屏幕”“窗口与层级”“运动与性能”“电视应用”“启动与显示器”分类并自动保存。支持像素 / 高清、四种材质、15–120 FPS 上限、位移阈值和惯性参数。可固定在指定任务栏 GUI 程序下方；目标不可见后退回普通层级。自定义表情支持常见图片及 GIF 首帧，导入为本地静态 PNG。

## 系统面板

四个模块共用卡片、精简表格、完整表格、筛选、排序和分栏详情。先看简短解读，需要时查看“证据 / 全部字段”。“仅看重点”减少正常项目，完整信息可导出 CSV。默认保持阅读位置，手动重排或开启实时排序；“定格阅读”仍在采样，“暂停采样”才停止采集。

- 性能与设备：硬件分类、驱动、CPU / 内存 / 磁盘 / 网卡及进程资源。可按路径合并软件、按占用或启动时间排序。不可读字段明确标注；工作集汇总可能重复计算共享页。
- 磁盘与快照：目录浏览、元数据快照、断点续扫、新增 / 修改 / 删除比较。不是内容备份或原子快照，扫描期间的变动和无权限目录会影响比较。
- 网络：软件概览、连接、历史、网卡、流量曲线和实时捕获。可固定软件范围、按公网 / 本机 / 监听 / 上传等筛选。最近结束项暂时保留供阅读，过期速率不继续显示。
- 日志与安全：系统保护状态、事件日志、只读注册表、手动开启的程序 / 文件追踪。内置规则给出简短提示，不自动执行建议，不清理日志或修改注册表。

网络软件概览汇总已测 TCP；“实时捕获 · TCP / UDP”通过 Windows ETW 单独展示短连接和 UDP / IPv6 事件，避免重复累计。捕获需要管理员或事件跟踪权限，Windows 通常约一秒批量交付事件。权限不足、丢事件和容量丢弃会提示。连接历史与变化日志各保留最多 20,000 条，事件保留最近 10 分钟、最多 8192 个通信对象；退出清空，可提前导出。

PTR 反查不是请求域名或 URL，HTTPS 内容不可见。公网通信、上传和规则提示都不等于泄露或攻击。监测不保证捕获每个短连接，也不保证系统报告未遭篡改。程序生命周期约每秒采样，极短进程可能遗漏；目录变化通知不能可靠归因到修改程序。

关闭、最小化、切走或暂停相关监测会停止采集；曲线保留采样空白。信息解读在本机进行，不上传记录；PTR 使用系统 DNS。

## 电视应用（实验性兼容模式）

点击屏内快捷方式默认在电视中启动并自动接入；偏好设置 → 电视应用 → **快捷方式默认打开位置** 可选择 Windows 桌面。右键快捷方式可临时指定打开位置。Edge / Chrome / Brave 的程序及 `.lnk` 会请求新窗口，复用进程时也识别新窗口，已有窗口不受影响。未能识别的启动器可在机身右键 → 电视应用中手动接入。

**屏幕中不显示桌宠工具栏**，程序画面使用整个 LCD。接入、打开、释放和恢复全部窗口等管理操作集中在机身右键菜单；屏内 Shift+右键也可打开菜单。最多接入 8 个窗口，可选单应用和多窗口布局。

软件运行时，机身下方红色实体按钮亮起，点击后显示退出状态，等待电视内应用关闭后返回图标桌面；重复点击不会重复退出。无响应的独占应用进程会在超时后结束；共享浏览器仅关闭电视内窗口，保留桌面窗口。需要保存确认的应用不会强制结束，会提示先处理确认。右键菜单仍可选择仅释放、恢复窗口。普通模式下红色按钮打开命令助手。

`PicoPet.Input.dll` 保持投影鼠标的悬停状态，只过滤已接入目标线程错误的鼠标离开消息；真正离开、暂停或释放时清除，不抢夺键盘焦点。便携使用需保留同目录 DLL；当前仅支持可加载钩子的同权限 x64 软件，32 位及拒绝钩子的应用可能仍有悬停兼容问题。

已接入应用所属的无标题弹出菜单会合成到 LCD 内，超出画布时按比例缩小，并同步换算鼠标位置；已实测 Edge 主菜单展开和“设置”点击。独立文件选择器、带标题对话框及拒绝钩子的程序仍有兼容限制。

点击屏内控件后，Windows 原生键盘焦点交给应用。滚轮、水平滚轮和 Ctrl+滚轮操作屏内程序；在机身滚轮缩放电视。桌宠不再将 Ctrl+C/V 等改写为通用编辑消息，原生焦点下由应用处理自己的快捷键和输入法。复杂弹窗、拖放及部分应用的焦点行为仍可能不兼容。

**应用画面上限**默认 60 FPS，可设 5–60，独立于模型动画帧率。采集线程使用高精度计时，画面变化后直接通知电视刷新，最多积压一个通知，消除辅助进程和电视两层定时轮询；静止超过半秒后降低至最多 10 次/秒检测，有输入或画面变化即恢复。隐藏或暂停停止采样。上限不是保证值，窗口自身绘制及 PrintWindow 耗时仍会限制实际帧率。

**电视应用画布分辨率**默认自动补偿系统 DPI，按完整 LCD 的 800:500 比例计算，宽度限制在 1280–1920；150% 缩放时为 1536×960。固定档位为 800×500、1280×800、1600×1000，即时保存。画布独立于 Windows 桌面分辨率，电视缩放不改变应用布局；最终采样纹理为 800×500。网页长内容仍保留正常滚动，全屏交给应用自身控制。

这是同会话的窗口容器，不是完整虚拟系统或安全隔离。普通最大化限制在容器内，其他 GPU 界面、独占全屏和独立弹窗不保证兼容。通过菜单释放窗口、退出桌宠或桌宠主进程异常退出时，由辅助进程恢复仍存活窗口的原父级、样式和位置；红色按钮执行的是关闭电视内应用。

## 屏内终端

输入、输出和光标绘制在三维屏幕中，进入后保留当前大小。仅桌宠获得焦点时接收键盘输入，没有全局键盘监听。

普通 CMD 支持输入编辑、命令历史、Page Up / Down、Ctrl + V 粘贴、Ctrl + C 停止 / 重置。Esc 收起，Tab 切换助手模式。交互工具通过后台 Windows 控制台映射进屏幕；opencode 等需事先安装并配置 PATH。交互模式的方向键、Tab、Esc 传给工具，使用机身助手按钮收起。

工具兼容性取决于控制台协议和输出特性，不承诺完整兼容 Windows Terminal。展开命令视图适合长输出，也可在外部终端继续。命令以当前用户权限运行，外部工具按其配置联网。

## 性能与开发

静止按需渲染，运动按帧数上限调度；实际帧率受硬件、尺寸和负载影响。高清大尺寸开销更高。窗口平移复用画面，BVH 加速命中；支持的驱动异步读回，最多一个在途帧。隐藏、锁屏和休眠停止动画。

配置位于 %LOCALAPPDATA%\PicoPet：settings.ini、shortcuts.ini、expression.png / expression.ini。索引与运行记录也留在本机。

构建唯一入口为 native/build.ps1，版本只在 resources.rc 更新。运行 tools/run_checks.ps1 执行内置自检；tools/exercise_*.ps1 覆盖交互回归。公共测试代码点导入 test_support.ps1，避免截取其他脚本。系统窗口的隐藏表格 / 命令是回归工具的兼容接口。

| 修改范围 | 回归入口 |
| --- | --- |
| 终端尺寸、滚轮、菜单、自启动与显示器选择 | exercise_zoom_menu.ps1 |
| 屏内终端和交互工具 | exercise_embedded_console.ps1、exercise_opencode.ps1 |
| 电视应用、输入、退出和窗口恢复 | exercise_app_workspace.ps1；加 `-Browser` 验证 Edge 新窗口接入、关闭及已有窗口保留 |
| 卡片、筛选、排序 | exercise_cards.ps1、exercise_readability.ps1 |
| TCP / UDP 捕获 | exercise_network_capture.ps1 |
| 渲染和运动性能 | measure_pipeline.ps1、measure_frame_pacing.ps1 |

界面测试需要交互桌面，会移动鼠标和改变设置，提前备份配置。构建、截图和报告写入 build / dist / output，不提交。模型资源更新见 tv3d/README.md；历史变化以 Git 为准。
